Important: gradle/wrapper/gradle-wrapper.jar must be generated by running Gradle locally, because the wrapper JAR is a binary produced by the Gradle distribution. Run the following in your project root (requires Gradle installed on your machine):

  gradle wrapper --gradle-version 8.12

This will create gradle/wrapper/gradle-wrapper.jar and ensure the wrapper is complete.

After generating the JAR, add and commit it to the repo (or create a follow-up PR). Example:

  git add gradle/wrapper/gradle-wrapper.jar
  git commit -m "Add gradle-wrapper.jar (generated by Gradle 8.12)"
  git push origin add-gradle-wrapper-8.12
